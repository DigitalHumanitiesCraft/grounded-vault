# 00_sources/

Original source files (PDF, PPTX, DOCX, CSV and other formats) live here, exactly as they arrived. The folder is gitignored except for this file. Whether an original is committed is set out in `knowledge/operations.md` § Acquire, and the rights of an individual source are recorded in the `license` and `confidential` metadata of its Markdown representation, as `knowledge/schema.md` § Source metadata defines.

Once a document original is ingested, exactly one Markdown representation in `10_markdown/` names it in its `source` field.
