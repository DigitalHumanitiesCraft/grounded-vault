# MOC: Instances

What a real instance did, recorded from the instance itself. It covers the source situation of a build, the runs of the validator and the machine review, and the findings these produced. Every assertion of this topic rests on data the instance wrote about its own work, so the standing of each figure depends on how that record came about, and the datasets state their own limits.

- [[30_assertions/first-review-pass-concentrates-at-the-distillate-layer]], the size and the layer distribution of the first review pass of this instance.
- [[30_assertions/modality-drift-is-the-most-frequent-recorded-defect]], the recorded defects and the categories they fall into.
- [[30_assertions/no-recorded-verdict-was-contradicts-or-not-in-the-text]], the two harshest verdicts of the contract went unused.

## Open questions

- Which of the recorded findings generalize beyond the instance that produced them?
- How many pairs the second and third pass covered is not recorded, because later passes examined selections of reworked pairs.
- Whether the reported pair counts match the pairs actually cut cannot be checked without a machine readable review log.
- Whether the same distribution of categories arises with a reviewer from another model family is untested here.
