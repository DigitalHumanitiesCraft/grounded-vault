# MOC: Agentic Workflow

Assertions on the division of labour between the producing agent, the reviewing model and the human roles, on the action layer that routes an agent onto declarative rule documents, and on what changes in the work when the artifact rather than the model carries the obligation.

## Open questions

- Which failure modes of a producing agent does the structural obligation catch, and which does it leave untouched?
- What does the action layer cost in agent effort per produced statement, and is that figure recoverable from the instances?
