# Block references are specific to Obsidian

## Statement

Block references are specific to Obsidian and are no part of the standard Markdown format, and links containing them do not work outside Obsidian. The vendor states this as an interoperability note on the page that describes the syntax, and the table of supported Markdown extensions lists the block reference as a row.

## Support

- [[20_distillates/publications/obsidian-help-internal-links#^s16]] — states that block references lie outside standard Markdown and that links carrying them fail outside Obsidian
- [[20_distillates/publications/obsidian-help-obsidian-flavored-markdown#^s5]] — places the block-reference row in the vendor's table of supported Markdown extensions
