# Distillate

At commit `79cd1d3`, the Grounded Vault terminology defines the distillate as the source-bound knowledge document, one per source, which condenses what the source says into core statements, each anchored to the passage of the Markdown representation it was taken from, and holds the source's terms, open questions and optional appraisal beside them.
