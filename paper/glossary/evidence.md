# Evidence

At commit `79cd1d3`, the Grounded Vault terminology defines evidence as a [[glossary/grounding]] relation that has passed verification, relational and deliberately rare, so that a fresh vault contains grounding and evidence arises only through review. [[10_markdown/documents/grounded-vault-index-79cd1d3#^idx23]] In the same state, verification is human expert review by the verification role, which alone establishes evidence.
